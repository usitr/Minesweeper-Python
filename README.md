# Minesweeper

A  Minesweeper by Python using the Turtle graphics library. Done in grade11.

## Features
- Three difficulty levels: Easy, Medium, and Hard
- First click safety
- Recursive opening of connected empty cells
- Left-click to reveal openable cells, right-click to place and remove flags
- Mine counter and game timer
- Custom graphical interface built with Python Turtle

## Technologies
- Python
- Turtle
- Python standard libraries (`random`, `time`, `pathlib`)

## How to Run
- Enter `0`, `1`, or `2` in the terminal to select a difficulty.

## About
I originally created this project while learning Python in high school. The game logic and interface were implemented using Python's Turtle module, including recursive empty-cell expansion and custom image assets.
